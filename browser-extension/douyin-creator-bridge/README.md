# DataLens Douyin Creator Bridge

这是 DataLens 的浏览器扩展骨架，用于把抖音创作者中心当前作品详情页中已经展示的数据发送到本机 DataLens。

## 使用方式

1. 打开 Chrome 或 Edge 的扩展管理页。
2. 开启开发者模式。
3. 选择“加载已解压的扩展”。
4. 选择本目录：`browser-extension/douyin-creator-bridge`。
5. 启动 DataLens，本地地址保持 `http://127.0.0.1:8900`。
6. 打开抖音创作者中心作品详情页。
7. 点击扩展按钮，再点击“读取并发送”。

## 说明

- 扩展只读取当前页面已经展示的文本和指标。
- 当前解析字段包括播放、点赞、评论、收藏、分享、完播率、平均播放时长、2s 跳出率、5s 完播率、平均播放占比、观后搜索词和可见低谷点。
- 不绕过登录、不处理验证码、不批量撞接口。
- 页面结构变化可能影响字段识别，失败时可以继续使用 DataLens 的手动录入或 CSV 导入。
