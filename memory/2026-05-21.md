# 2026-05-21 工作记录

## 抖音创作者中心数据导入

- 新增 `browser-extension/douyin-creator-bridge/`，用于在已登录的抖音创作者中心作品详情页读取当前可见数据。
- 扩展只做用户可见页面数据读取，不处理登录、验证码、风控绕过或批量爬取。
- 新增本机接口 `POST /api/creator/douyin/import-current`，按作品链接或作品 ID 精确匹配视频库，匹配到则更新，匹配不到则新建视频。
- 导入后默认把素材状态标记为“待复盘”，方便进入决策中心继续分析。
- 修复连续导入不同抖音作品时误写入上一条视频的问题：新增 `creator_item_id` / `creator_page_url` 专用字段，导入只按作品 ID 或页面 URL 精确匹配；标题相同也不会自动合并。
- 扩展新增发布时间解析，支持从页面文本识别 `2026-05-17 19:30`、`2026/05/17 19:30`、`2026年5月17日 19:30` 等格式，导入时写入 `publish_date` / `publish_time`；解析不到才使用当天日期。

## 视频库 UI 修复

- 修复大图卡片里视频画面与标题/数据重叠的问题：视频画面只保留播放器，标题和核心指标移到视频下方。
- 大图卡片核心指标从 4 个小格改为可换行的数据条，避免完播率、播放量等被截断。
- 大图卡片的视频控制条改为鼠标进入视频区域时显示、离开时隐藏，默认不再一直占住画面底部。
- 右侧详情栏的“观看质量”从固定 5 列改为自适应网格，在窄栏中显示 2 列，不再出现 `1...` 这种省略。
- 打开编辑视频弹窗前会自动关闭右侧详情抽屉，避免弹窗和抽屉同时出现、互相遮挡。
- 编辑弹窗宽度调整为 `min(760px, calc(100vw - 32px))`，减少表单挤压。
- 上传视频后会自动尝试转成浏览器兼容的 H.264/AAC MP4；成功则替换为兼容文件，失败则保留原文件并提示可手动转码。
- 大图卡片核心指标改为稳定 2x2：播放、完播、互动、收藏；完播/互动未录入时显示 `--`，避免误判为真实 0%。
- 修复筛选漏项：保存筛选视图会保存账号筛选，应用视图会同步账号控件；导出 CSV 会带上方向、设备组、违规、账号筛选，后端导出接口也支持这些参数。
- 修复快捷筛选状态误导：点击“有违规”会同步刷新下方违规下拉显示；点击“近7天/近30天/高互动”会清掉上一次快捷筛选留下的违规条件，避免条件残留但 UI 看不出来。
- 视频库视图模式支持默认记忆：切换“详细/紧凑/大图”后写入 `localStorage`，下次打开自动恢复上次模式。
- 梳理账号控件语义：视频库保留“筛选账号”，账号管理页保留“当前账号”；设置当前账号只作为录入/计划默认值，不再自动改写视频库账号筛选。修复账号 select 被通用下拉和账号搜索下拉重复包装的问题，避免出现两个功能一样的“全部账号”。
- 优化账号搜索下拉：面板最小宽度 220px，账号名单行省略，平台名靠右显示，禁止横向滚动，避免账号名换行挤成窄条。
- 视频库新增第四种“运营表格”视图：包含当前筛选统计卡片、密集宽表、固定勾选/素材/标题列、缩略图悬停大预览，适合按账号、方向、状态、播放、完播、互动、评论、收藏、违规和复盘字段做运营检查。
- 运营表格新增表头拖拽列宽：支持拖动列与列之间的分隔线调整宽度，写入 `localStorage`，并提供“恢复默认列宽”；同时固定勾选/素材/标题列的 sticky 偏移会随列宽更新，改善右侧操作列与行内容不对齐的问题。
- 视频库日期筛选改成范围控件：新增“今天/昨天/近7天/近30天”快捷入口，默认日期为当天；空日期时只显示“年/月/日”占位，不再暴露浏览器原生 `yyyy/mm/dd` 占位。
