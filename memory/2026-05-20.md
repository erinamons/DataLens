## 抖音创作者中心浏览器扩展骨架

- 新增 `browser-extension/douyin-creator-bridge/`。
- 扩展运行在 `creator.douyin.com`，只读取当前页面已经展示的文本和指标。
- 不绕过登录、不处理验证码、不批量撞接口。
- 扩展将数据发送到本机接口：`POST /api/creator/douyin/import-current`。
- DataLens 接口会按作品链接/标题匹配已有视频，匹配到则更新，匹配不到则新建视频。
- 新导入的视频默认 `material_status="待复盘"`，方便进入决策中心复盘。
- README 已增加浏览器扩展说明。

## 创作者中心观看质量字段

- 新增视频字段：`avg_watch_seconds`、`bounce_2s_rate`、`completion_5s_rate`、`avg_watch_ratio`、`watch_trend`、`post_watch_search_terms`。
- 扩展解析字段：完播率、平均播放时长、2s 跳出率、5s 完播率、平均播放占比、观后搜索词、可见低谷点。
- `POST /api/creator/douyin/import-current` 会把观后搜索词和趋势数据以 JSON 字符串写入视频表。
- 视频详情卡片、详情抽屉和复盘弹窗会展示观看质量、观看趋势摘要和观后搜索词。
